# Website UI kit

Recreation of the karkalabs.ai marketing page, from the `karkalabs-site` codebase (ground truth: `src/sections/Hero.tsx`, `StudentsSection.tsx`, `AudienceStub.tsx`, copy from `src/content/copy.ts`).

- Hero on the board-grid motif; content bottom-anchored; audience chip nav.
- Students section on ink: pinned-scroll board sequence recreated as click-through steps (Back / Next step) driving the parabola scene, caption track, ConceptChip and StepProgress.
- Parents / Schools / Tuition stubs keep the site's honest `TODO:VB` placeholders and unconnected lead forms — that's faithful, not unfinished.
- Posters use `assets/imagery/student-hero.png` as stand-in; real posters are stills from the demo videos (not in sources).
