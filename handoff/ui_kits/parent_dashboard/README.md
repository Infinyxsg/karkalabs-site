# Parent dashboard UI kit

Recreation of the KarkaLabs Parent dashboard from the screenshot in `Demo videos/CBSE Onboarding/Screenshot 2026-08-09 224316.png` (copy: `reference/cbse-app.png`).

- "Learning progress" two-tone serif heading, per-child session list.
- Session cards: date + metric chips (Confidence ▲ n, Accuracy, excellent/needs_support), prose summary, WHAT THEY LEARNED / QUESTIONS ASKED / FOUND DIFFICULT columns, SUGGESTED NEXT SESSION callout.
- Email in the header is a placeholder; the screenshot's real address was not copied.
