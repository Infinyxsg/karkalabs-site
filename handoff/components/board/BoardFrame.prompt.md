The Karka board's chrome — the visual signature of the brand. Pale blue-grey scene ground (`#EEF2F4`, sampled from the product board), 20px radius, the ONLY deep shadow in the system, with the tutor's caption track beneath and a teal voice pill.

```jsx
<BoardFrame
  poster="/assets/imagery/student-hero.png"
  tutor="Aarya" tone="ink"
  caption="Gravity only pulls down. So only the upward part shrinks as the ball rises."
  showVoice
/>
```

`tone="ink"` for the dark Students section, `tone="paper"` for light audience sections. Pass children to draw custom board content.
